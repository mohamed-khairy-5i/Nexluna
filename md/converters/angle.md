# محول وحدات الزوايا | درجة، راديان، غراد — Nexluna

> حوّل وحدات الزوايا بدقة: درجة، راديان، غراد، دقيقة قوسية، وثانية قوسية. أداة مجانية من Nexluna.

حوّل بين وحدات قياس الزوايا — مفيد للرياضيات والهندسة والفلك.

**الرابط:** https://nexluna.netlify.app/converters/angle.html

## الوحدات المدعومة

| الرمز (code) | الوحدة |
| --- | --- |
| `deg` | درجة |
| `rad` | راديان |
| `grad` | غراد |
| `arcmin` | دقيقة قوسية |
| `arcsec` | ثانية قوسية |
| `turn` | دورة |

## أسئلة شائعة

### كم درجة في الراديان؟

1 راديان ≈ 57.2958 درجة.

### كم درجة في الدورة الكاملة؟

الدورة الكاملة = 360 درجة = 2π راديان.
