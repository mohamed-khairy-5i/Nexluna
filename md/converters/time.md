# محول وحدات الوقت | ثانية، دقيقة، ساعة، يوم، سنة — Nexluna

> حوّل وحدات الوقت بدقة: مليثانية، ثانية، دقيقة، ساعة، يوم، أسبوع، شهر، وسنة. أداة مجانية من Nexluna.

حوّل بين وحدات الوقت المختلفة بسهولة — من المليثانية حتى السنة.

**الرابط:** https://nexluna.netlify.app/converters/time.html

## الوحدات المدعومة

| الرمز (code) | الوحدة |
| --- | --- |
| `ms` | مليثانية |
| `s` | ثانية |
| `min` | دقيقة |
| `h` | ساعة |
| `day` | يوم |
| `week` | أسبوع |
| `month` | شهر |
| `year` | سنة |

## أسئلة شائعة

### كم ثانية في الساعة؟

الساعة الواحدة = 3600 ثانية.

### كم يوم في السنة؟

السنة الشمسية ≈ 365.25 يوم.
