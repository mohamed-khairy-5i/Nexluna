# محول وحدات الطول | متر، كيلومتر، ميل، قدم — Nexluna

> حوّل وحدات الطول والمسافة بدقة: متر، كيلومتر، سنتيمتر، مليمتر، ميل، ياردة، قدم، وإنش. أداة مجانية وسريعة من Nexluna.

استخدم محوّل الطول لتحويل المسافات بين النظامين المتري والإمبراطوري بدقة فورية. أدخل القيمة واختر الوحدتين لتظهر النتيجة مباشرة.

**الرابط:** https://nexluna.netlify.app/converters/length.html

## الوحدات المدعومة

| الرمز (code) | الوحدة |
| --- | --- |
| `km` | كيلومتر |
| `m` | متر |
| `cm` | سنتيمتر |
| `mm` | مليمتر |
| `mi` | ميل |
| `yd` | ياردة |
| `ft` | قدم |
| `in` | إنش |
| `nmi` | ميل بحري |

## أسئلة شائعة

### كم سنتيمتر في المتر؟

المتر الواحد يساوي 100 سنتيمتر و1000 مليمتر.

### كم متر في الميل؟

الميل الواحد يساوي 1609.344 متر أي نحو 1.60934 كيلومتر.

### كيف أحوّل من قدم إلى متر؟

اضرب عدد الأقدام في 0.3048 لتحصل على القيمة بالمتر.
