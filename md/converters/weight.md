# محول وحدات الوزن | كيلوغرام، غرام، رطل، أونصة — Nexluna

> حوّل وحدات الوزن والكتلة بدقة: طن، كيلوغرام، غرام، مليغرام، رطل، وأونصة. أداة مجانية وسريعة من Nexluna.

حوّل بين وحدات الوزن المترية والإمبراطورية بسهولة. مثالي للطبخ والشحن والتمارين والاستخدامات اليومية.

**الرابط:** https://nexluna.netlify.app/converters/weight.html

## الوحدات المدعومة

| الرمز (code) | الوحدة |
| --- | --- |
| `t` | طن |
| `kg` | كيلوغرام |
| `g` | غرام |
| `mg` | مليغرام |
| `lb` | رطل |
| `oz` | أونصة |
| `st` | ستون |
| `ct` | قيراط |
