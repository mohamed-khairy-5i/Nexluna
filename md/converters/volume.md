# محول الحجم والسعة | لتر، متر مكعب، جالون، كوب — Nexluna

> حوّل وحدات الحجم والسعة بدقة: متر مكعب، لتر، مليلتر، جالون، كوارت، كوب، وأونصة سائلة. أداة مجانية من Nexluna.

مثالي للطبخ والوصفات: حوّل بين اللتر والمليلتر والكوب والجالون والوحدات المكعبة بدقة فورية.

**الرابط:** https://nexluna.netlify.app/converters/volume.html

## الوحدات المدعومة

| الرمز (code) | الوحدة |
| --- | --- |
| `m3` | متر مكعب |
| `L` | لتر |
| `mL` | مليلتر |
| `gal` | جالون أمريكي |
| `galUK` | جالون إمبراطوري |
| `qt` | كوارت |
| `pt` | باينت |
| `cup` | كوب |
| `floz` | أونصة سائلة |
| `tbsp` | ملعقة كبيرة |
| `tsp` | ملعقة صغيرة |

## أسئلة شائعة

### كم مليلتر في اللتر؟

اللتر الواحد يساوي 1000 مليلتر.

### كم لتر في الجالون الأمريكي؟

الجالون الأمريكي يساوي نحو 3.78541 لتر.

### ما الفرق بين الجالون الأمريكي والإمبراطوري؟

الجالون الأمريكي = 3.78541 لتر، والجالون الإمبراطوري (البريطاني) = 4.54609 لتر — أي أن الإمبراطوري أكبر بنحو 20% (1 جالون UK = 1.20095 جالون US). لهذا نفصل بينهما بوضوح في المحوّل.
